# LETI Admission Analyzer

> Анализ конкурсных списков на поступление в СПбГЭТУ «ЛЭТИ» (ФКТИ). Парсинг, моделирование распределения по приоритетам и Telegram-уведомления.


Скрипт автоматически:
- собирает данные с официальных страниц приёмной комиссии ЛЭТИ,
- имитирует конкурсный отбор с учётом **приоритетов направлений** и **количества бюджетных мест**,
- отправляет уведомление в Telegram при обновлении позиции указанного абитуриента.
